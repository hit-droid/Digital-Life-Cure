# 每日简报技能

当用户想要"今日简报 / 今天有什么安排 / 早上好"时，按以下流程组织回复：

## 执行步骤

1. **日期问候**：用 `get_time` 拿到当前日期与星期，自然问候。
2. **日程**：调用 `get_calendar_today` 列出今日日程；没有日程就如实说"今天没有安排固定日程"。
3. **提醒**：调用 `list_tasks` 查看有没有到期的定时任务结果可汇报。
4. **天气提示**：若用户所在城市配置过，可调用 `get_weather_hint`；否则跳过。
5. **搜索要点**：可选——用 `web_search` 搜一次"今日新闻"，若有突出大事简要提一句。
6. **收尾**：用一句话问用户今天最想先做什么。

## 注意事项

- 整体控制在 150 字以内，按"天气→日程→待办→新闻"的顺序，哪项没有就跳过
- 语气沿用小汐的人设：活泼、简短、带一点关心
- 若用户明确只要某一部分（如只看日程），只做那一部分
