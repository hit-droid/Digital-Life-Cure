# 深度调研技能

当用户需要深入调研某个主题时，按以下流程执行，不要直接凭记忆作答：

## 执行步骤

1. **拆解主题**：把用户问题拆成 2~4 个需要查证的关键子问题。
2. **搜索概览**：对每个子问题调用 `web_search`（query 用精确关键词，必要时加年份/地域限定）。
3. **抓取正文**：从搜索结果中挑选 2~3 个可靠来源，调用 `web_fetch` 读取正文（max_chars 设 6000）。
4. **交叉验证**：若不同来源说法矛盾，在报告中如实指出。
5. **输出报告**：用 Markdown 结构输出：
   - 一句话结论放在最前面
   - 分节说明每个子问题，标注信息来源（域名即可）
   - 末尾给出"不确定性/待核实"小节

## 注意事项

- 每个子问题至少搜 1 次，总搜索不少于 3 次，否则不算完成调研
- 抓取失败时换下一个来源，不要用猜测填充
- 报告控制在 600 字以内（除非用户要求详细）
- 若用户问题不是事实类调研（如闲聊、创作），不启用本技能
